## איפה נשמרים הנתונים

הנתונים נשמרים ב־`localStorage` של הדפדפן, תחת המפתח `taskJournal`.

> ⚠️ **חשוב:** לכל מכשיר/דפדפן יש רשימת משימות **נפרדת**.
> המשימות במחשב לא מסתנכרנות אוטומטית עם הטלפון.
> כדי להעביר משימות בין מכשירים: **🗄 גיבוי** במכשיר אחד → **📂 שחזור** בשני.
> מומלץ לעשות גיבוי מדי פעם — ניקוי היסטוריית הדפדפן מוחק את המשימות.

---

## דרכי שימוש

**1. אפליקציית Windows** (מותקנת במחשב)
מותקנת ב־`%LOCALAPPDATA%\PersonalTaskJournal\` ורצה כאפליקציית Edge עצמאית עם אייקון בתפריט התחל.
לעדכון לגרסה האחרונה מהריפו:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\update-windows-app.ps1
```

**2. דפדפן / טלפון**
פשוט פותחים את https://feldmoni.github.io/Task-Manager/ — עובד בכל דפדפן.

**3. מקומי**
פתיחה ישירה של `index.html` בדפדפן.
